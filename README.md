# nspire-usbaudio

Sound from a TI-Nspire CX or CX II through a USB audio device (USB Audio Class 1), for Ndless
programs. `NOTES.txt` describes it.

It is the USB sound library of [gpSP for the TI-Nspire](https://github.com/jadenmcdaniels/lr-gpsp-nspire),
whose Makefile builds it from a directory beside `gpsp/`. It needs
[nspire-usbshim](https://github.com/jadenmcdaniels/nspire-usbshim) beside it.
